准备（开始前读一遍）

1. 安装被测版本

方式 A（推荐，测打包产物）：双击 artifacts/macos/ZCodeStatusLight-v0.3.0-alpha.1-macos-arm64.dmg，把 ZCodeStatusLight 拖入 Applications，从启动台打开。

方式 B（开发版）：终端执行 apps/macos-native/.build/debug/ZCodeStatusLight。

若 macOS 提示"已损坏，无法打开"（常见于下载分发的 ad-hoc 签名包）：执行 xattr -cr /Applications/ZCodeStatusLight.app 后重开。本机直接构建的包一般不会触发。

2. 事件模拟（大部分状态测试不需要真实 ZCode 会话）

打开"终端"，把下面整块存成脚本 /tmp/zsl-demo.sh（chmod +x /tmp/zsl-demo.sh），后面 C/D 组直接调用其中的函数：

#!/bin/bash
# 用法: zsl-demo.sh yellow|red|green|bash|session2|done2
E='http://127.0.0.1:57310/event'
post() { curl -s -m 2 -X POST "$E" -H 'Content-Type: application/json' -d "$1" -o /dev/null -w "%{http_code}\n"; }
case "$1" in
  yellow)   post '{"event":"user_prompt_submit","session_id":"t1","project":"演示项目","project_dir":"/tmp/demo","prompt_preview":"正在演示任务","turn_id":"turn-1"}' ;;
  red)      post '{"event":"permission_request","session_id":"t1","project":"演示项目","project_dir":"/tmp/demo","last_tool":"Edit","turn_id":"turn-1"}' ;;
  bash)     post '{"event":"permission_request","session_id":"t1","project":"演示项目","project_dir":"/tmp/demo","last_tool":"Bash","turn_id":"turn-1"}' ;;
  green)    post '{"event":"stop","session_id":"t1","project":"演示项目","project_dir":"/tmp/demo","turn_id":"turn-1"}' ;;
  session2) post '{"event":"user_prompt_submit","session_id":"t2","project":"另一个项目","project_dir":"/tmp/other","prompt_preview":"第二个会话","turn_id":"turn-2"}' ;;
  done2)    post '{"event":"permission_request","session_id":"t2","project":"另一个项目","project_dir":"/tmp/other","last_tool":"Edit","turn_id":"turn-2"}'
            post '{"event":"stop","session_id":"t2","project":"另一个项目","project_dir":"/tmp/other","turn_id":"turn-2"}' ;;
esac

每条命令都应输出 204。若输出 000（连接失败）说明 App 没在运行。同一轮测试要结束会话时，stop 必须携带与 user_prompt_submit 相同的 turn_id，否则会被协议拒绝（这是规格行为，不是 bug）。

3. 常用路径

  • 设置文件：~/Library/Application Support/ZCodeStatusLight/settings.json
  • ZCode Hook 配置：~/.zcode/cli/config.json（F 组会修改它，App 会先自动备份）
  • Hook 备份目录：~/.zcode/cli/.zcode-status-light-backups/
  • 彻底重置测试状态：托盘退出 App → 删除设置文件目录 → 重启

4. 建议顺序

A → B → C → D → E → F（F 会真实写 Hook 配置，放后面）→ G（需第二台显示器）→ H。全程约 40–60 分钟。
